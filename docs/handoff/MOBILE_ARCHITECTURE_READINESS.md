# Cội Nguồn · Mobile architecture readiness

**Đánh giá tại Core Integration Gate M1.2B.** Giữ React/Web/PWA làm client dùng chung. Đặt quy tắc phả hệ, validation, mapper và kế hoạch ghi trong core TypeScript. IndexedDB là adapter trình duyệt. UI chọn tệp, camera, canvas, PDF và in dùng Web APIs. Core đã sửa trong M1.2B không cần Node API ở client; Node chỉ tham gia build, test và máy chủ Gemini. Xử lý ảnh, parse tệp và mọi thao tác mạng diễn ra ngoài transaction. Transaction IndexedDB chỉ bao dữ liệu cần đọc/ghi.

| Hạng mục | Hiện trạng và điều kiện xác minh |
|---|---|
| **PWA hiện tại** | VitePWA/Workbox precache shell, script và styles. IndexedDB giữ hồ sơ tách khỏi cache; Cloud đã build service worker, Desktop M0 đã kiểm reload khi origin server dừng với cache ấm. GP-CLOUD-006 về icon manifest và ca installed cold-offline/update còn chờ. Cài đặt và chạy offline cần cùng origin ổn định. |
| **iOS Safari** | Kiểm riêng Safari và ứng dụng thêm vào Home Screen. Luồng cài thủ công và hộp thoại in/chia sẻ khác Chrome. Đo ảnh HEIC/camera theo khả năng decode của thiết bị; ảnh lỗi có thông báo chọn JPG/PNG. Kiểm IndexedDB sau đóng app, bị hệ điều hành thu hồi, nâng cấp PWA và thiếu dung lượng. Chromium viewport mô phỏng chưa đủ để kết luận Safari. |
| **Android Chrome** | Kiểm Chrome và PWA đã cài với camera/thư viện, không gian lưu gần đầy, background/resume và tải JSON/PDF qua file picker. Test Chromium 390 px đã xác minh chọn/hủy/lưu ảnh cả khi đã ngắt mạng sau khi tải shell, và tạo PDF raster. Camera thật, Android file picker và vòng đời tiến trình còn chờ thiết bị thật. |
| **Media và quota** | Chân dung chỉ ghi khi lưu hồ sơ, cùng một transaction. Decode từ object URL, resize cạnh lớn nhất xuống 400 px, nén ảnh mới và giải phóng object URL/canvas. Ảnh camera lớn vẫn tốn RAM khi decode. Đo `navigator.storage.estimate()`, kích cỡ ảnh/ghi âm và snapshot trên iOS/Android trong QA; quota thay đổi theo trình duyệt, origin và thiết bị. |
| **Độ bền offline** | IndexedDB giữ dữ liệu theo origin/profile. SW cache shell và có thể tải lại tài nguyên ứng dụng; browser/OS vẫn có thể dọn dữ liệu website hoặc người dùng chủ động xóa dữ liệu. Có thể dò `navigator.storage.persist()` khi triển khai chính sách độ bền, với backup JSON làm đường phục hồi khả dụng. Kiểm mất mạng khi commit, mở lại và khôi phục sau khi dữ liệu được dọn. |
| **Backup giữa thiết bị** | JSON v1 giữ ID, metadata, liên kết và data URL của ảnh/tư liệu đã lưu trong app. Tệp cũ có URL ngoài giữ nguyên URL và được cảnh báo; khả năng truy cập media có thể khác trên thiết bị đích. JSON chứa dữ liệu gia đình dạng đọc được, nên chuyển qua kênh do chủ dữ liệu chọn. Thử Android → Desktop → iOS và chiều ngược lại, đối chiếu 8 store và mở ảnh/PDF. |
| **Capacitor sau này** | Có thể bọc cùng web build và đặt adapter mỏng cho camera/file picker, share và print nếu Web APIs thiếu. Chốt lifecycle WebView, origin/đường nâng cấp và quy trình import JSON khi chuyển từ PWA; WebView và trình duyệt có kho riêng. Chạy bộ hợp đồng transactions/restore trên WKWebView và Android WebView trước khi cân nhắc storage adapter khác. |
| **Cloud sync nếu được phê duyệt** | Cần opt-in theo gia phả, xác thực và quyền từng vai trò, mô hình conflict theo phiên bản và tombstone, outbox có retry/idempotency, kiểm đồ thị và hợp nhất nhiều bản ghi, thiết kế media, mã hóa và khóa, phục hồi/retention/xóa dữ liệu, cùng hợp đồng migration và offline-first. Transport ở ngoài local transaction. Chốt phạm vi gửi, consent và quyền sở hữu trước khi thêm dịch vụ. |

Chân dung, tra cứu, quan hệ, nhập và backup JSON chạy cục bộ khi shell khả dụng. PDF giữ pipeline trình duyệt; nếu canvas không hỗ trợ khổ/độ dài hồ sơ, UI hướng dẫn In/Lưu PDF hoặc nêu bản tải xuống là fallback văn bản. Gemini là thao tác online khi người dùng gọi; sửa đổi M1.2B không gửi dữ liệu gia đình tự động. Google Fonts là phụ thuộc giao diện ngoài origin hiện có. URL ảnh ngoài còn tồn tại trong một số dữ liệu v1; xuất JSON giữ nguyên giá trị mà không fetch URL đó.

Giai đoạn này chỉ đánh giá kiến trúc. Kiểm chứng trên iOS Safari/Android Chrome, cold-offline sau cài và đường tải tệp là các ca còn chờ. Xem [bàn giao Desktop](M1_2B_CLOUD_TO_DESKTOP.md).
